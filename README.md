# 🧮 Smart Calculator (Algorithm Showcase)

Инженерный калькулятор на Java, главной особенностью которого является ручная реализация парсинга математических выражений. Проект демонстрирует владение классическими алгоритмами Computer Science и структурами данных.

---

## 🚀 Особенности проекта
- **Zero-dependency:** Вычисления реализованы без использования сторонних библиотек (типа Exp4j или JS Engine).
- **Два алгоритмических подхода:** Код разнесен по веткам для демонстрации разных архитектурных решений.
- **Поддержка сложных выражений:** Работа со скобками, приоритетами операций, унарным минусом и функциями ($\sqrt{x}$, $x^2$, $1/x$, %).
- **Интерфейс:** GUI на базе Java Swing с поддержкой ввода как мышью, так и с клавиатуры.

---

## 🧠 Реализованные алгоритмы

Проект разделен на две ветки в зависимости от метода обработки строки:

### 1. Shunting Yard (ветка `main`)
Реализован алгоритм «Сортировочная станция» Эдсгера Дейкстры.
- **Lexical Analysis:** Разбиение строки на токены (числа, операторы, функции).
- **RPN:** Преобразование инфиксной записи в Обратную польскую нотацию.
- **Stack Machine:** Вычисление итогового результата с использованием стека.
- **Сложность:** $O(n)$ по времени и памяти.

### 2. Recursive Descent (ветка `recursive-descent`)
Реализован парсер на основе формальной грамматики выражений.
- **LL(1) Parsing:** Построение неявного дерева синтаксического разбора.
- **Приоритеты:** Обработка приоритетов через иерархию методов (`parseExpression` -> `parseTerm` -> `parseFactor`).
- **Рекурсия:** Элегантная обработка вложенных скобок и функций.

## 📂 Как переключаться между версиями

Чтобы посмотреть разные реализации парсера, используйте стандартные команды Git:

# Перейти на версию с алгоритмом Дейкстры (Стек)
git checkout main

# Перейти на версию с Рекурсивным спуском
git checkout recursive-descent

# 💻 Запуск

mvn clean package
java -cp target/calculator-1.0-SNAPSHOT.jar com.t1.calculator.Main
